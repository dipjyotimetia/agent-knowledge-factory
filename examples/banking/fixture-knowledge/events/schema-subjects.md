# Subjects

Confluent Schema Registry subjects follow `{topic}-value`.

`movement-lifecycle-v1` therefore uses subject `movement-lifecycle-v1-value`.
`transaction-events` uses `transaction-events-value`.
`payment-events.v1` uses `payment-events.v1-value`.

# KF-13 Recall

## Goal

Keep PostgreSQL full text as the default, and offer a local rerank when the first hit is the wrong page.

## Inputs / outputs

- `SEARCH_MODE` unset or any value other than `hybrid` leaves search as full text plus title trigram.
- `SEARCH_MODE=hybrid` reranks those hits with `index.HashEmbed` and cosine similarity. No model is called.
- `evaluations.scoreHits` accepts the answer in any returned hit, not only the first.
- `docs/sql/pgvector.sql` is an optional extension script. `migrations/` does not install pgvector, and CI does not require it.

## Non-goals

- A hosted embedding API.
- Replacing full text with a vector index.

## Definition of done

`go test ./internal/index ./internal/evaluations` passes. Hybrid mode changes order only. A case whose answer is in the second hit still passes.

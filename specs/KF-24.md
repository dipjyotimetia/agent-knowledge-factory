# KF-24 — Secure trace references and approved revision isolation

**Priority:** P0 · **Depends on:** KF-22, KF-23 · **Supersedes:** KF-11 filesystem reference semantics

## Goal / defect

`domain.GapReport.TraceRef` is untrusted MCP input; `Steps.Prepare` calls `os.ReadFile` on it. `index.Get` accepts explicit SHA and filters only item-level approved/stable status; staged rows may satisfy those flags. Prevent local-file access and candidate exfiltration, including by guessed SHA. Create separate internal evaluation access.

## Contract

`trace_ref` becomes optional opaque `trace:<uuid>` (lowercase canonical UUID, max 42 chars); no path, URL, traversal, URI decoding or arbitrary lookup. Add `trace_records(workspace_id,id,owner_actor,agent_run_id,schema_version,content_digest,sanitised_payload,created_at,expires_at,status)` with composite constraints. `TraceStore.Put(ctx,principal,runID,normalised)` returns ID; `GetForInvestigation(ctx,workspace,attemptID,traceID)` returns sanitised permitted record. For this spec support trusted local operator import via `kfactory traces import --file <operator-local-path> --run-id <id>`; later KF-26 adds HTTP. CLI opens only the operator-selected local regular file, no server filesystem access; max 1 MiB before decode; refuse symlinks/nonregular files and document platform restrictions. CLI sends/uses sanitised payload; never stores source path. Existing JSON import supported after sanitisation, malformed input rejected. Link gap trace only when trace belongs to workspace and run, caller is owning actor or trusted curator; return generic not found for other IDs. Invalid trace ref = 400, missing/expired/unauthorised = 404. Revalidate ownership at processing time; expiry after intake results in no trace evidence, recorded reason.

Public read contract: `PublishedReader.Search/Get` default to active release only; explicit `revision` accepted only if equals active SHA (historical reads deferred to authorised audit tooling). Nonactive returns same not-found response as missing, including formerly published, quarantined and staged. Internal `CandidateReader` requires non-user-facing candidate ID plus evaluation operation scope; read only exact private namespace. `SearchAt` and generic candidate access must not be wired to HTTP/MCP. Candidate storage uses private candidate IDs or separate tables, not a public Git SHA namespace; separate DB grants where feasible, mandatory code boundary and RLS. Even reviewer routes cannot serve candidate bodies unless a future separately authorised review contract; reviewers use Git PR. Never cache across workspace/release/actor scope.

## Implementation sequence

1. Add trace migration, store and validation; update `schemas/gap-report.schema.json`, `domain.ValidateReport`, `gaps.Service.Report`, CLI, MCP and tests. Strict parse once; do not strip path to make valid. Replace `os.ReadFile` in `Prepare` with `TraceStore` lookup. Existing file-path refs are legacy-invalid; migration nulls or quarantines old values with safe count, not raw path audit. Document reimport procedure. Remove nosec suppression for unsafe path. No request-controlled `os.Open` anywhere on worker path.
2. Sanitise recursively using existing `policy` plus structured allowlist and redaction; reject secrets in unknown keys, strip credential headers/PII fields, limit bytes, depth, turn count (max 200), role enum, UTF-8; do not promise exhaustive PII detection. Reject ambiguous formats; no raw body in error. Redact before DB/Temporal/model. Expiry and deletion implemented via retention.
3. Separate candidate/release index APIs, make public `Get` enforce active pointer in same transaction as query; public `Search` uses active pointer; candidate query never calls public Get to bypass. Recheck permission/withdrawal in KF-31. Disable public explicit historical reads intentionally, document client compatibility. Update API handlers, MCP resource/read and CLI search/get; ensure logs do not reveal existence.
4. Bootstrap existing active release via KF-22; existing staging rows not presumed safe. Add DB integration tests under app role; ensure cleanup never removes current active index. Fix tests that used public Get to inspect candidate to use internal test reader.

## Security / failure handling

Reject `../../`, absolute paths, `file://`, `http://`, percent-encoded paths, NUL and malformed IDs before DB. Bound import and retention, reject secrets without persisting rejected bytes. Authorise trace access via workspace/run/actor; no customer content, no raw OTLP. Public data and private candidate are distinct capabilities; any unconfigured trust policy fails closed. No leaks via search count, resource URI, error detail, evaluation endpoint or logs. Review existing `/v1/review` output to ensure it contains metadata only, not private raw evidence or candidate bodies for agents.

## Acceptance criteria / tests

- **24-A:** MCP gap report with path/URL, symlink target and traversal rejected; no filesystem open on server, no content in log or proposal.
- **24-B:** Valid opaque trace links to exact workspace/run; another actor/workspace, unknown, expired or deleted trace gives generic denial. Legacy path is not resolved even after migration.
- **24-C:** Import oversized, malformed, deeply nested JSON and secrets/PII; safe redacted result or reject; scan DB, logs and workflow history for sentinels.
- **24-D:** Stage stable approved-looking item; HTTP/MCP search/get/resource cannot retrieve candidate by guessed SHA or URI. Public explicit SHA of nonactive denied. Internal evaluator sees candidate with scoped capability.
- **24-E:** Concurrent promotion/get returns coherent single release, never private data; cross-workspace test under real RLS. Active revision remains accessible after staging cleanup.
- **24-F:** `schemas` and example fixtures updated, legacy CLI migration documented, integration demo uses trace ID not path.

Add tests under `internal/traces`, `internal/gaps`, `internal/index`, `internal/api`, `internal/mcpserver`, `cmd/kfactory`; shared gates. **Done:** no arbitrary local file access from submitted gap, all public read paths enforce active revision, internal candidate evaluation still works.

## Non-goals

Remote OTLP endpoint, per-document ACL system, agent trace analytics or historical audit API.

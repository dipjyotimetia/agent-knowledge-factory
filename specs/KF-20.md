# KF-20 Data-access guidance

## Goal

Teach an agent which source to query, without copying the rows into the knowledge repository.

## Inputs / outputs

- `knowledge_items.item_type` accepts `data-access` (`migrations/007_data_access.sql`).
- An OKF concept whose `type` is `DataAccess` or `data-access` is indexed as that item type.
- `examples/banking/fixture-knowledge/events/movement-query.md` names the source and says not to copy rows.
- Category `bad-data-access` can create `events/data-access.md` from a contract or policy sentence. The page tells the reader where to query and forbids a copy of the data.

## Non-goals

- Executing the query. The factory does not connect to the system the page names.

## Definition of done

`go test ./internal/index ./internal/curator` passes. Search with `--type data-access` returns the movement-query page. The page body does not contain a sample of live rows.

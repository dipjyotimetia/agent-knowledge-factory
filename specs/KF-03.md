# KF-03 Git sources

## Goal

Fetch authoritative banking contract files from GitHub without ever writing to that repository, and pin every byte to a commit SHA plus a sha256 digest.

## Inputs / outputs

- Input: allowlist (host, owner, repo, path prefixes, SHAs), optional bearer token from the environment, path and revision.
- Output: `Snapshot` with location `github://owner/repo/path`, revision, digest, ACL visibility, classification, and content. A 304 returns `NotModified` and no new bytes.

## Non-goals

- Indexing the bytes (KF-04).
- Opening pull requests (KF-08).
- Calling GitHub from tests. Tests replay `testdata/`, recorded from `distributed-systems` commit `8e6680d683ac728f0f089bd60e4a96576ab4ed45`.

## Interfaces

`github.Adapter.Fetch`. There is no create, update, or merge method.

The allowlist rejects:

- hosts other than the configured list, including redirects and a base URL pointed at a link-local address
- refs that are not a 40-character SHA in the pin set (`main` is rejected)
- paths outside the prefixes, absolute paths, and `..`
- `http` except loopback, which exists so httptest can run

429 responses retry with a capped `Retry-After`. `X-RateLimit-Remaining: 0` stops further calls. Tokens are not copied into error strings.

## Failure modes

- Not allowlisted: error before any HTTP call.
- 404: `ErrNotFound`.
- Rate limit exhausted: `ErrRateLimited`.
- Response larger than 2 MiB: error, content discarded.

## Tests

Recorded README and Avro schema round-trip byte for byte, with digest, public ACL, and classification `contract`. Disallowed paths make zero requests. Redirects, rate limits, ETag 304, and a metadata-host SSRF attempt are covered.

## Definition of done

`make test` passes. The banking evidence the curator will cite is the recorded file, not a live call and not a write to `distributed-systems`.

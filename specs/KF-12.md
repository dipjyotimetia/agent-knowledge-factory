# KF-12 Connectors and a second writer

## Goal

Let the curator read more than one GitHub tree, and let an operator materialize a knowledge tree without opening a pull request.

## Inputs / outputs

- `sources[].provider: notion` fetches one pinned page from an allowlisted host. The body is wrapped as untrusted text and stored as classification `secondary`.
- `sources[].provider: slack` fetches one pinned message the same way.
- `secondary` evidence cannot ground a claim. Contract and policy evidence still can.
- `publish.Directory` writes files under a local root. It refuses absolute paths and `..`. It does not delete unrelated files and it does not merge.
- GitHub remains the only publisher that opens a pull request.

## Non-goals

- Writing back to Notion or Slack.
- A live workspace in CI. Tests use a fake HTTP server.

## Definition of done

`go test ./internal/ingestion/notion ./internal/ingestion/slack ./internal/publish` passes. A host outside `allow_hosts` is rejected. A Notion or Slack body alone does not satisfy `curator.Validate`.

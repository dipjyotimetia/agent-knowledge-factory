# KF-18 Human delta

## Goal

A line a reviewer adds on the merged tree, and that the curator did not propose, becomes a follow-up gap.

## Inputs / outputs

- `HumanLines` compares the merged file with the proposal's old text, new text, and the pre-merge body.
- `noteHumanDelta` files one `stale-instruction` gap. `client_event_id` is `human-delta-` plus the merge SHA, so a retry links to the same investigation.
- The expected text is the added lines. The observed text is the proposal's new text.

## Non-goals

- Rewriting the merged file. The follow-up waits for the next curation pass.

## Definition of done

`go test ./internal/workflows ./internal/demo` passes. `REVIEWED_SENTENCE` on the merged skill is stored as a linked gap and is present in the published body.

# KF-21 Contradiction scan

## Goal

Find two documents that state different values for the same fact, and file one gap.

## Inputs / outputs

- `curator.DefaultClaimPatterns` extracts a dedupe key and a status value.
- `ScanClaims` reports a conflict when one pattern captures more than one value across the tree.
- `RaiseContradictions` files category `contradictory-sources` with `client_event_id` `contradiction-` plus the pattern name. A repeat links to the open investigation.
- Conflicting evidence inside `movement-dedupe-key` still escalates and does not edit.

## Non-goals

- A general entailment model. Only the configured patterns are compared.

## Definition of done

`go test ./internal/curator -run ScanClaims` passes. Two dedupe keys in the tree produce one conflict. One key produces none. `RaiseContradictions` files that conflict once per pattern name.

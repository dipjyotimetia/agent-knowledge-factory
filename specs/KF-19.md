# KF-19 Curator cadence

## Goal

The curator runs on its own schedule, separate from the agent that filed the gap.

## Inputs / outputs

- `factory-worker` registers `DrainOpenWorkflow` and creates Temporal schedule `akf-curation-<workspace>`.
- `CURATION_INTERVAL` overrides the period. The default is 24h.
- Each run calls `RefreshEvidence`, then `RaiseContradictions`, then `Prepare` and `Open` for gaps in `new` or `triaged`.
- The minute loop still reconciles the default branch and enforces retention. It does not replace the schedule.

## Non-goals

- Starting the schedule when `TEMPORAL_ADDRESS` is unset. The worker stays idle in that case.

## Definition of done

`go test ./internal/workflows -run Drain` passes. A second schedule create whose error text contains `already` does not fail the worker.

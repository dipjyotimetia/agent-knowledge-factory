# KF-14 Review view

## Goal

Give a signed-in operator one read of the open work, without a merge button.

## Inputs / outputs

- `GET /v1/review` requires a bearer token and returns that token's workspace only.
- The body lists the latest gaps, proposals, evaluation runs, and evidence links.
- The route does not signal Temporal and does not call a merge API.
- `POST /v1/gaps/{id}/approval` stays a separate route. It accepts `reviewer` or `curator`. An `agent` token receives 403.

## Non-goals

- A browser application.
- Merging from this process. GitHub remains the merge authority.

## Definition of done

`go test ./internal/api` passes. An agent token cannot approve. The review payload contains no merge URL that this service would call.

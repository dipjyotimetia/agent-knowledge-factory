# KF-05 MCP

## Goal

Give an agent five tools and a `kb://` resource for the workspace this process is configured for. The protocol is the official Go SDK, which negotiates MCP `2026-07-28` and the older versions that SDK supports.

## Inputs / outputs

- `knowledge.search` → ranked hits with revision
- `knowledge.get` → one approved item
- `knowledge.report_gap` → gap id and state `new`
- `knowledge.submit_feedback` → feedback id
- `knowledge.get_gap_status` → state
- `kb://{authority}/{+path}` → markdown body

The workspace id is the server's configuration. A tool argument for a different workspace is rejected and the index is not queried.

## Non-goals

- Git write tools, source-host search, or merge.
- HTTP MCP. stdio is the v1 transport. `factoryd -mcp` serves it.
- Durable de-duplication (KF-06). The MCP tests use an in-memory reporter. The Postgres reporter replaces it in the next epic without changing the tool schema.

## Interfaces

`mcpserver.New`. `index.Service` and `gaps.Memory` satisfy the reader and reporter interfaces.

## Failure modes

- Unknown URI: MCP resource-not-found.
- Mismatched workspace: tool error, no index call.
- Invalid gap report: tool error, nothing stored.

## Tests

In-memory client/server session:

- initialize negotiates `2026-07-28`
- a client that asks for `2025-06-18` still calls `knowledge.search`
- the tool list is exactly the five knowledge tools
- search, get, and resource read return the stale movement guide
- a report returns state `new`
- a cross-workspace argument fails

## Definition of done

`go test ./internal/mcpserver` passes against `github.com/modelcontextprotocol/go-sdk` v1.8.0.
